# 建筑公共资讯站改造

## M1：建筑单主题与只读入口

当前只启用 building。访客无需登录；不新增用户、角色、会话或邮件服务。

- `shared/public-site.ts` 是页面、接口、采集/发布的统一启用策略。
- 新阅读页面不挂载旧登录、账户同步、AI 设置或原始热榜组件。
- `00-public-site` 中间件先于旧中间件执行，仅放行资讯读取、版本读取、收录附件转发；其余 API 默认拒绝。
- 停用主题返回 404；URL 重复 topic 返回 400；附件也在处理函数内检查主题，不能只依靠中间件。
- Mac 的 `--source all` 现在仅遍历已发布主题的启用来源。旧累积 result.json 不被删除，但停用主题不再进入新批次。
- 构建时从历史 JSON 生成仅含启用主题的运行快照。历史 JSON 暂留仓库用于迁移与回滚，不声称已完成生产数据与代码分离。
- 公共响应不含模型配置、运行错误、来源采集状态或数据库诊断。版本轻量检查约五分钟一次，完整列表仅在用户选择刷新后更新。

## 未完成阶段

M2：核实 D1 运行数据，建立受后台凭据保护的增量发布和去重检查；迁移后删除对仓库生产快照的依赖。M1 不创建/删除数据库，也不改动账户付费方案。

M3：SQL/服务端分页、完整检索和游标翻页。目前仍继承最近最多 5,000 条的读取边界，不能宣称数据库分页已经完成。

M4：附件防刷、全站预算和运行监测，独立暂停 relay 的操作能力。

生产预检：Pages 项目已有 NEWSNOW_DB 绑定；现有部署凭据访问 D1 管理列表返回 401。这不等于 Worker 绑定不可用；下一阶段要通过绑定验证实际读写与迁移，不能据此删除或重建数据库。

## 验收边界

测试必须包含停用主题/旧接口直接访问拒绝、旧 URL 无资讯请求、无登录与 AI 请求、二级地区选择、菜单互斥、点击外部与 Esc 关闭、DOC/DOCX/PDF 预览不退化。所有后续回退必须保留 public-site 入口策略。

## M2—M4 实施（2026-09-09）

新的公开读模型是 D1 `building_*_v3` 表，保留旧 v1/v2 表且不删除历史。生产构建中的仓库快照为空，历史 JSON 只作为冻结的迁移输入，不再由正常采集修改。

### 发布与回退边界

每个发布事务最多 20 条元数据/决策/状态项，512 KiB 请求上限；一个采集周期可以有多个独立、原子提交的事务。事务有唯一编号、规范化内容摘要、当前版本前置条件和持久回执。事务中途失败全部回滚；已提交事务重试不重复写入。决策/来源状态更新不推进公开内容版本。旧采集时间的记录不覆盖较新的记录。原始文章/附件字节永不进入新表。

Cloudflare 发布先创建本次专用预览，临时使用现有 NEWSNOW_DB 绑定和预览专用迁移凭据，通过原生绑定验证/迁移，核对已有公开元数据后再更新 main。失败不主动切换生产站。迁移只做一次，后续部署不使用旧快照覆盖新数据。预览变量、绑定和本次部署在最后清理。不得回退到开放旧 AI/API 的版本。

### Mac 一次性公钥登记

新版 worker 拉取 main 后，在任何采集/AI 前执行 `node tools/ai-bridge/publisher.mjs prepare`。首次生成 Ed25519 私钥到忽略目录 `.data/building-publisher/private-key.pem`（0600）；只将公开 JWK 登记到 `shared/building-publisher-keys.json` 并通过一次配置提交部署。私钥不出本机、不进日志、不进仓库。公钥未部署时暂停本轮，下一轮重试，不运行 AI；已经登记的公钥被移除时不会自动重新授权。

之后资讯发布通过签名后台接口完成，不再提交生产快照。签名绑定方法、路径、时间和请求体；访客没有登录也没有写入凭据。只保留 publish/operate 机器能力，不建设用户系统。云端发布完成不能替代本机新版拉取、密钥登记和真实发布回执的核验。

本机维护命令（在仓库根目录）：

```sh
node tools/ai-bridge/publisher.mjs status
node tools/ai-bridge/publisher.mjs pause-relay
node tools/ai-bridge/publisher.mjs resume-relay
```

### 分页、检索、缓存

默认每页50条，上限100条。D1先执行栏目/省市/类型/来源/时间/重要度/标签/搜索过滤再分页；没有5000条历史截断。游标绑定内容版本、全部筛选、每页数量和日期窗口锚点，版本变化返回409，用户刷新重新开始。新城市标识含所属省，兼容旧城市名URL。搜索为元数据文字的参数化子串匹配，不是全文搜索引擎或向量检索；大规模查询扫描量需持续监测。标签候选最多1000个，不影响搜索或按已有标签值查询历史记录。

版本接口只读版本元数据，不装载整库。常用结果以内容版本为键，在有界进程缓存/Cloudflare Cache API中保留60秒，搜索查询不写边缘缓存。缓存不是数据库，也不缓存附件。缓存命中前仍检查启用主题并读取当前版本；外层响应不缓存。

### 附件运行控制

浏览器直连原站优先。仅对已收录建筑附件启用流式转发，20 MiB单文件上限保持。默认每IP每分钟6次、同IP2个并发、全站20并发、每日2000次转发和5 GiB保守字节额度。按UTC日计数。这些是应用预算，不是Cloudflare账单硬上限。

D1事务先预留单文件最坏字节数，流式结束/取消后结算实际发送字节；结算丢失时不退款，过期并发租约不代表消耗未发生。IP仅以每日加盐摘要参与短期限制，不向公开接口返回。暂停只阻止新的转发，不影响资讯和原站入口。无凭据访客不能修改限额。没有开通新的付费方案、邮件服务或对象存储。
